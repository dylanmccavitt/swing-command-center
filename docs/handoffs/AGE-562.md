# AGE-562 Handoff

## Status

Implemented AGE-562 on branch
`dylanmccavitt2015/age-562-robinhood-csv-variant-hardening`.

Robinhood CSV import remains file-only and local. No broker login, scraping,
credential handling, uploads, APIs, order execution, or automated trading were
added.

The CSV parser now accepts additional account-activity and realized gain/loss
header variants for transaction type, security description, net cash amount,
sale proceeds, adjusted basis, quantity sold, disposed date, and disallowed
loss fields. The focused variant tests use only tiny synthetic fixtures.

Import review now separates proceeds from recognized realized P/L. Accepted
account-activity sells without basis can count as buying-power proceeds, but
they still produce $0 recognized realized P/L, reserve, and pay-myself until
basis is imported or manually reviewed. Matching accepted realized gain/loss
rows continue to take precedence over account-activity proceeds.
