# AGE-528 Handoff

## Status

Merged into `main` through GitHub PR #3:
<https://github.com/DylanMcCavitt/swing-command-center/pull/3>. Canonical
`/Users/dylanmccavitt/projects/swing-command-center` has been fast-forwarded to
the merge commit, and AGE-528 is ready to move to `Done` in Linear after this
handoff closeout commit lands.

The app now models manual local holdings with share count, average cost,
current price, market value, cost basis, unrealized P/L, portfolio weight, and
concentration state. Risk settings include editable alert weight, max
single-position weight, tax reserve rate/toggle, cash runway target, and active
trading sleeve. Default concentration language defines the 25% alert as the
soft warning and the 30% cap as the trim-scenario threshold.

Profit-lock outputs are framed as manual scenario tickets, not buy/sell
certainty. Scenarios cover trim-to-target weight, locking 10%, 20%, or 25% of
unrealized gains, recovering cost basis, and raising a specific cash amount.
Each ticket estimates proceeds, realized gain, editable tax reserve, net cash,
remaining shares, and remaining portfolio weight.
