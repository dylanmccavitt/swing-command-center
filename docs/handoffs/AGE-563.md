# AGE-563 Handoff

## Status

Implemented AGE-563 on branch
`dylanmccavitt2015/age-563-research-queue-polish`.

PR: https://github.com/DylanMcCavitt/swing-command-center/pull/17

The Research + Codex queue now behaves as a manual daily research desk for any
tracked ticker. HIMS and General watchlist names are first-class: request JSON
includes a `researchDesk` context with source/import checklists, the queue UI
shows the selected ticker/lane/status/source checklist, and the research card
surfaces catalyst, invalidation, risk, planned-entry context, stop context,
target context, review date, source notes, source counts, and imported source
metadata.

Result validation now rejects duplicate normalized source ids and direct entry,
stop, app-target, buy/sell, or guaranteed-outcome copy. Import handling uses a
typed helper that preserves the card identity/trade setup, merges only research
draft fields, keeps the review state as `needs_review`, and returns source-count
feedback.

The branch was rebased onto latest `origin/main` after AGE-562 merged as commit
`d2fa059` (`AGE-562: harden Robinhood CSV variants`). The only conflict was
`CHANGELOG.md`; both AGE-562 and AGE-563 entries were kept.
