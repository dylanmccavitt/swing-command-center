# Research Queue

This folder is for local Codex/ChatGPT-assisted research artifacts.

- `requests/*.json` are generated by the app when a research card queues a
  Codex request.
- `results/*.json` are written manually by a Codex/ChatGPT/Deep Research worker
  after processing a request.
- Generated JSON in both folders is ignored by git.
- `.gitkeep`, this README, docs, and schemas are committed so the local queue
  shape survives fresh checkouts.

The app validates result JSON before importing it into an editable research card
as AI-drafted / Needs review. It does not call OpenAI APIs or require an API
key.
