# AGE-534 Handoff

## Status

Implemented the Run research layer on branch
`dylanmccavitt2015/age-534-0607-run-research-for-ai-stack-watchlist-cards`.

The research card editor now has `Run research`, `Run layer`, and `Mark
reviewed` controls. A selected-symbol run and a selected AI-stack layer run both
use the typed `ResearchProvider` boundary to load transparent source context,
then draft thesis, catalyst, invalidation, risk notes, review date, and source
notes into the existing editable research card.

Each run shows source URLs, retrieved timestamps, freshness, and a clear
AI-drafted / needs-review state before the user marks a card reviewed. Loading,
error, empty-source, and stale-source states are explicit. Draft copy is framed
as manual-review research only, not a guaranteed recommendation or buy/sell
instruction.

## Next

Review the PR, then merge and fast-forward canonical `main`. After merge, move
AGE-534 to `Done`.

## Risks

- The current provider is a curated transparent source-pack provider. It links
  to source pages and normalizes drafts, but it does not scrape or summarize
  live article/body text.
- Research card edits and run state are still browser-session state only. Local
  persistence remains a future slice.
- Source freshness is based on provider timestamps. Future live providers should
  replace the curated timestamps with real observed/published timestamps.
