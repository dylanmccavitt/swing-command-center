# AGE-530 Handoff

## Status

Implemented the AI-stack research watchlist and setup tracker on branch
`dylanmccavitt2015/age-530-0507-ai-stack-research-watchlist-and-setup-tracker`.

The app now has a dense AI-stack research desk with fixed layer grouping for
hyperscalers, GPU/chip designers, foundries, memory, semiconductor equipment,
EDA/IP, networking, power/cooling, data centers, and energy. The watchlist seed
includes the current holdings AAPL, GOOG, NVDA, and IREN plus placeholder names
for the other stack layers.

Each research card is editable in browser-session state and includes thesis,
catalyst, invalidation, risk notes, planned entry, stop, target, and review
date. Each card also includes manual trade setup fields for entry trigger, stop
level, target, max loss, planned scale-out, invalidation, and time horizon.

The candidate view filters by layer, minimum checklist score, current holdings,
and missing inputs. The score only measures completed fields; UI and docs state
that it is not an AI model, guarantee, expected-return ranking, or trade
recommendation.

## Next

Review the PR, then merge and fast-forward canonical `main`. After merge, move

## Risks

- Research card and trade setup edits are browser-session state only. Local
  persistence remains a future slice.
- Placeholder theses are intentionally lightweight starting points for manual
  editing, not current recommendations.
- The checklist score does not validate whether the thesis or setup is good; it
  only checks whether required fields are filled.
