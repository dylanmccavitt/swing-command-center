# Research Queue

This folder is for local Codex/ChatGPT-assisted research artifacts. It is a
manual research desk queue for any tracked ticker, including General watchlist
names such as HIMS.

- `requests/*.json` are generated by the app when a research card queues a
  Codex request. Each request includes `researchDesk.sourceChecklist` and
  `researchDesk.importChecklist` so the worker knows what to verify.
- `results/*.json` are written manually by a Codex/ChatGPT/Deep Research worker
  after processing a request. The file name should match the request's
  `expectedResultPath`.
- Generated JSON in both folders is ignored by git.
- `.gitkeep`, this README, docs, and schemas are committed so the local queue
  shape survives fresh checkouts.

The app validates result JSON before importing it into an editable research card
as AI-drafted / Needs review. Results should be short stock reports with
source-reported analyst target/rating context and editable entry/risk/target
context, not buy/sell instructions. The app does not call OpenAI APIs or
require an API key.

Worker checklist:

1. Read the request JSON and `docs/codex-research-worker.md`.
2. Research the ticker manually from public sources. Use company primary,
   filings/regulatory context, recent news, analyst context, sector/peer
   context, and price/setup context when available.
3. Write exactly one result JSON file at `expectedResultPath`.
4. Keep `reviewState` as `needs_review` and use the exact disclosure string.
5. Include URL, publisher, accessed timestamp, optional published timestamp,
   and a short note for every source.
6. Keep catalyst, invalidation, target, stop, and planned-entry fields framed as
   source context for manual review only.
