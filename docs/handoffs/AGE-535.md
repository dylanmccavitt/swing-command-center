# AGE-535 Handoff

## Status

Implemented the profit target and stop-limit scenario planner on branch
`dylanmccavitt2015/age-535-0707-profit-target-and-stop-limit-scenario-planner`.

The scenario desk now supports a selected holding or research card and editable
inputs for current price, average cost, shares, max loss dollars, desired
risk/reward, target gain percent, trim percent, support/reference price,
stop-limit buffer, cash target, and time horizon. The planner outputs planned
entry, stop level, stop-limit note/example limit, first target, stretch target,
trim size, estimated proceeds, estimated gain/loss, remaining shares, and
remaining value. Each output includes the reason for the calculation.

Outputs remain framed as manual scenarios for review only. The helper surfaces
guardrails for missing cost basis, missing/stale/mock market data, invalid
risk/reward, invalid trim percent, missing stop basis, and long-position stops
at or above planned entry. No brokerage integration, order execution,
automated trading, tax advice, or private lot seed data was added.

## Next

## Risks

- Planner inputs are browser-session state only; they are not persisted.
- Profit-lock tickets still use the manual lots table and existing portfolio
