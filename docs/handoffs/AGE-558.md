The app now has a file-only Robinhood CSV import/review layer for official
account activity CSVs and realized gain/loss CSVs. Imported rows normalize into
buys, sells, dividends, interest, transfers, fees, or unknown rows. Robinhood
rows stay `needs_review` until accepted; only accepted sell rows map into the
existing reviewed sell-fill buying-power model. Matching realized gain/loss
rows take precedence over account-activity sell rows for proceeds, basis,
realized P/L, holding period, and wash-sale fields.

## Risks

- Keep this file-import only. No Robinhood login, credentials, scraping,
  session handling, unofficial Robinhood API calls, Robinhood Crypto Trading
  API usage, order execution, or automated trading.
- CSV exports can vary. Unknown or incomplete rows are kept visible with
  reconciliation statuses instead of being guessed.
- Missing basis, proceeds, holding period, wash-sale, fee, and tax fields must
  stay missing unless imported or manually reviewed.
- Tax buckets are planning helpers only, not tax advice or filing documents.
- Browser file chooser upload could not be automated through the in-app Browser
  runtime; parser, normalization, review gating, and tax/export behavior are
  covered by focused tests.
