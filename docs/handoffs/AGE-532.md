## Verified

- Seeded holdings render as AAPL, GOOG, NVDA, and IREN.
- Live market data rendered with visible source/timestamp as `Alpaca IEX`; the
  watchlist prices updated between browser snapshots during the dev-server pass.
- Entering local shares and average costs moved the dashboard from empty state
  to `4 filled in / 0 need details`, rendered allocation rows, and produced
  ranked gain-lock ideas.
- Profit-lock and target/stop scenarios produced concrete shares, proceeds,
  realized gain/loss, reserve, net cash, stop-limit, and remaining-position
  outputs. The browser pass used AAPL lots and confirmed a ready AAPL price plan.
- Manual trade-ticket actions created local journal rows through the `Plan` and
  `Executed` buttons.
- Manual sell fills can be created locally. A sample AAPL filled sell with
  starting cash and marked reinvested cash updated buying power to `$563.04`.
- Robinhood realized gain/loss CSV import is review-gated. The imported NVDA row
  stayed out of buying power while pending, then after accepting the row it
  updated filled proceeds to `$1,799.00` and buying power to `$1,705.54`.
- Robinhood tax-planning buckets rendered after acceptance, including
  `+$200.00` short-term P/L and a `$124.75` reserve estimate with the existing
  manual sell included.
- Desktop width `1440x1400` and mobile width `390x900` rendered the core app
  surfaces with no horizontal document overflow.
- Browser console warnings/errors were empty in the in-app Browser session.

## Remaining Post-MVP Work

- Add durable local persistence for holdings, research cards, journal rows,
  sell fills, and Robinhood import review state.
- Keep market-data credentials local. Production or preview environments need a
  real secret-bearing backend/proxy before live data can leave the local dev
  setup.
- Harden Robinhood CSV support against more export variants and keep unknown or
  incomplete rows visible instead of guessed.
- Keep the Codex research queue manual unless a later issue explicitly adds a
  separate worker; the app does not call OpenAI APIs or silently use a Codex
  subscription.
- Add broader browser regression coverage once the MVP flows stabilize.

## Risks

- No Robinhood sync exists. Robinhood data is file-only local CSV import with
  manual review/acceptance.
- No broker login, scraping, credentials, order execution, or automated trading
  exists.
- Missing basis, proceeds, holding period, wash-sale, fee, and tax fields must
  stay missing unless imported or manually reviewed.
- Tax reserve and tax-planning outputs are planning helpers only. They are not
  tax advice, filing documents, or broker statements.
- MVP state is still browser-session local unless exported/imported manually.
