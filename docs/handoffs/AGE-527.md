# AGE-527 Handoff

## Status

Implemented the live market-data provider slice on
`dylanmccavitt2015/age-527-0207-live-market-data-provider-with-alpaca-first-fallback`.

The app now has a typed `MarketDataProvider` boundary with Alpaca Market Data as
the first provider. Auto mode uses the local Vite dev proxy when Alpaca market
data keys are present and falls back to deterministic mock quotes when keys are
missing or the request fails. The UI polls holdings plus the seed research
watchlist every minute and labels source, freshness, and quote timestamps.

## Next

Review the PR, then merge if the market-data fallback behavior and watchlist
seed are acceptable. After merge, sync canonical `main` and move AGE-527 to
Done.

## Risks

- Alpaca live calls require local environment keys and the Vite dev proxy;
  static preview builds will show mock fallback quotes unless an equivalent
  proxy exists.
- IEX/free-feed quotes are labeled as IEX and are not consolidated SIP data.
- The research watchlist seed is intentionally small and can be adjusted in a
  later issue without touching provider behavior.
